# KHU Live App — API Reference

Base URL (production): `https://khu-backend.onrender.com` (replace with your
own Render URL). Interactive docs are also auto-generated by FastAPI at
`/docs` (Swagger UI) and `/redoc`.

All request/response bodies are JSON. Dates are `"YYYY-MM-DD HH:MM"`
unless noted.

---

## Public — read-only

These require no authentication and are what the frontend uses directly.

| Method | Path | Description |
|---|---|---|
| GET | `/api/health` | Backend status, cache freshness, circuit-breaker state |
| GET | `/api/leagues` | All 8 leagues, in display order |
| GET | `/api/standings/all` | Standings for every league |
| GET | `/api/standings/{league_key}` | Standings for one league (e.g. `premier_league_men`) |
| GET | `/api/fixtures` | Upcoming fixtures — **past-dated matches are filtered out automatically**, checked fresh on every request |
| GET | `/api/results` | Completed results, grouped by league, most-recent-first within each league |
| GET | `/api/live` | Currently-live matches |
| GET | `/api/teams/all` | Every team across every league |
| GET | `/api/team?url=&name=` | One team's profile — position, form, upcoming fixtures, **every result this season** and a `season_summary` (matches listed, W/D/L, goals for/against, played per table). Also returns a `squad` list (name, shirt number, position, captain, photo flag, goals), read fresh on every request. Built from cached standings/fixtures/results data, not scraped fresh (see ARCHITECTURE.md §6) |
| GET | `/api/match?url=` | Detail for one match. Scraped details plus, when the match is in our cache, `league`, `state`, `scorers`, `cards` and logo URLs (the KHU match page itself doesn't publish scorers) |
| GET | `/api/players/{player_id}` | One player's page: details, season stats, goals log, team link. `player_id` is 12 hex characters (shown in `/api/team` squads and top scorers). Rate-limited |
| GET | `/api/players/{player_id}/photo` | The player's photo (cached for a day, `nosniff`, sandboxed CSP). 404 when none |
| GET | `/api/players/top-scorers?league_short=` | Goals leaderboard. Merges admin/agent season stat lines (authoritative) with goals tallied from scorers recorded on results — no double counting |
| GET | `/api/matches/history` | The permanent match archive: filter by `league_short`, `season`, `team`, `kind` (`results` or `fixtures`), `date_from`, `date_to`. Matches with a status notice carry `status_info` |
| GET | `/api/seasons`, `/api/seasons/{label}` | Saved past seasons (final tables, results) |
| GET | `/api/history/honours` | Roll of honour: the team in position 1 of each league, per saved season |
| GET | `/api/sponsors/active` | The sponsor to show (if any), within its dates |
| POST | `/api/analytics/hit`, `/api/analytics/install` | Private, cookie-free counts (screen views, installs). Respects Do Not Track |
| GET | `/api/tournaments` | All tournaments with `matches_total` / `matches_played`. Separate from league data |
| GET | `/api/tournaments/{id}` | One tournament: details, matches grouped by stage (chronological: first game at the top, Final last), computed group tables and `rosters` (real team names per gender/section, used for dropdowns) |
| GET | `/api/playoffs/nlm` | National League playoff bracket |
| GET | `/api/logo?url=` | Proxies a KHU-hosted team logo image (works around suspected hotlink protection) |
| POST | `/api/refresh` | Start a background refresh and return immediately (`Refresh started`, or `A refresh is already running`). Rate-limited to once per 60 s; only one scrape runs at a time |

## Admin — PDF fixtures

Gated by the `x-admin-token` header, matched against the `ADMIN_TOKEN`
environment variable.

| Method | Path | Description |
|---|---|---|
| POST | `/api/admin/fixtures/upload-pdf` | Upload a KHU season-calendar PDF. Multipart form with a `file` field. Parses and merges fixtures immediately — never overwrites a fixture the live scrape already has |
| GET | `/api/admin/fixtures/export-pdf-seed` | Export currently-stored PDF fixtures as JSON — save as `backend/pdf_fixtures_seed.json` and commit, so they survive Render's ephemeral disk permanently |

## Admin & agents — manual results

`POST`/`DELETE`/`GET .../list` accept **either** `x-admin-token`
(the master token) **or** `x-agent-token` (from `/api/agent/login`).
`export-seed` is admin-only.

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/admin/results/add` | admin or agent | Add/correct one result. Body: `{league_short, home_team, away_team, home_score, away_score, date, venue?}`. Applied to the live cache immediately |
| GET | `/api/admin/results/list` | admin or agent | List every manually-entered result, including its `match_key` (needed to delete) and `entered_by` |
| DELETE | `/api/admin/results/{match_key}` | admin or agent | Remove one manual result |
| GET | `/api/admin/results/export-seed` | admin only | Export for permanent seed-file persistence — same pattern as PDF fixtures |

## Admin & agents — tournaments

Tournaments live in their own tables and never touch league standings.
Group tables are computed from matches: 3 points per win, 1 per draw;
tiebreak is points → goal difference → goals for → name. Match
validation: both team names required and different; both scores or
neither (0–99); date as `YYYY-MM-DD` or `YYYY-MM-DD HH:MM`.

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/admin/tournaments/save` | admin | Create (no `id`) or edit a tournament. Body: `{id?, name, start_date, end_date, venue, description, status}` |
| DELETE | `/api/admin/tournaments/{id}` | admin | Delete a tournament and all its matches |
| POST | `/api/admin/tournaments/{id}/matches/save` | admin or agent | Admin: add (no `match_id`) or edit any match. Agent: only enter/correct the score (and fill a knockout slot) on an existing fixture; stage/date/venue are locked and team names must be in the tournament's roster. Body: `{match_id?, stage, group_name, home_team, away_team, home_score?, away_score?, date, venue}` |
| DELETE | `/api/admin/tournaments/matches/{match_id}` | admin only | Delete one match |
| GET | `/api/admin/tournaments/export-seed` | admin | Export for permanent persistence — save as `backend/tournaments_seed.json` and commit |

## Admin & agents — team / player stats

Same pattern as manual results (`set`, `list`, `DELETE .../{stat_key}`, `export-seed`), under
`/api/admin/team-stats/*` and `/api/admin/player-stats/*`. Seeds:
`team_stats_seed.json`, `player_stats_seed.json`.

## Admin — match corrections (fix KHU's mistakes, our app only)

When KHU's website lists a match under the wrong team or with a wrong score. Describe the match as KHU
shows it now, then say what is wrong. Applied on every refresh before anything else is merged, so the next
scrape cannot undo it; it stops applying by itself once KHU fixes its page.

| Method | Path | Auth | Purpose |
|---|---|---|---|
| POST | `/api/admin/match-corrections/set` | admin | `league_short`, `date`, `home_team`, `away_team` (as KHU shows) + any of `new_home_team`, `new_away_team`, `new_home_score`+`new_away_score`, `new_date`, `new_venue`, or `hide: true`. Replacement teams must exist in that league's table (exact name). `adjust_table` (default true) also moves the league table: the match is taken off the teams KHU's table counted it for and given to the right ones (played, W/D/L, goals, points, form), then positions are renumbered. Numbers typed in the team-stats form still win over everything. |
| GET | `/api/admin/match-corrections/list` | admin | Stored corrections, each with `applied_now` |
| DELETE | `/api/admin/match-corrections/{corr_key}` | admin | Remove; the match returns to KHU's version after a refresh |
| GET | `/api/admin/match-corrections/export-seed` | admin | Export (also inside the backup file and restorable) |

The league table follows the correction by default (see `adjust_table`). Untick it if KHU's table is already right for that match.

## Admin & agents — match status notices

`x-admin-token` or `x-agent-token`.

| Method | Path | Description |
|---|---|---|
| GET | `/api/admin/matches/search` | Find matches to mark (filters: league, team, kind). Returns each match's `match_key` |
| POST | `/api/admin/matches/status` | Set a notice: `postponed`, `rescheduled` (with `new_date`), `suspended`, `abandoned` (optional `minute`, `home_score`, `away_score`), `cancelled` or `awarded`, plus `reason`/`note`. Never changes the table |
| DELETE | `/api/admin/matches/status?match_key=` | Remove a notice |
| GET | `/api/admin/matches/export` | Admin only: archive, notices, analytics totals and sponsors for backups |

## Admin & agents — player profiles

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/admin/players/list?league=&team=` | admin or agent | Profiles and stat lines for one team |
| POST | `/api/admin/players/profile` | admin or agent | Create/edit: `{league_short, team_name, player_name, jersey 0-99, position, nationality, captain, bio (300), photo_data_url, remove_photo}`. PNG/JPEG/WebP only (checked by file bytes), max 300 KB, SVG refused. A shirt number identifies a player within a team: a second player with the same number is refused (422). | POST | `/api/admin/players/import-khu` | admin only | Body `{league_short}` (empty = all). Starts a background import of each team's public squad list from kenyahockeyunion.org: names, shirt numbers, photos. Only fills blanks, never overwrites. One run at a time; 4 starts per 10 minutes |
| GET | `/api/admin/players/import-khu/status` | admin only | Progress: teams read, players created/completed, photos added, teams that could not be read |

## Admin login

| Method | Path | Description |
|---|---|---|
| POST | `/api/admin/login` | Body: `{username, password}` checked against `ADMIN_USERNAME` / `ADMIN_PASSWORD`. Returns `{admin_token}`, used as `x-admin-token`. `503` if the env vars aren't set |

Both login endpoints share a throttle: 5 failed attempts from one IP
locks it out for 15 minutes (`429`).

## Error handling

- `401` — missing/invalid `x-admin-token` or `x-agent-token`
- `400` — invalid input (e.g. unknown `league_short`, malformed date)
- `404` — resource not found (e.g. deleting a `match_key` that doesn't exist)
- `429` — too many failed logins from this IP
- `409` — conflict (e.g. creating an agent username that already exists)
- `503` — cache not populated yet (very first startup, before the first refresh completes)

All error responses follow FastAPI's default shape: `{"detail": "message"}`.


## Security behaviour (see SECURITY.md)
- `POST /api/admin/login` returns a short-lived signed session (`admin_token`, `expires_in` seconds), not the master token. Send it as `x-admin-token`; the master `ADMIN_TOKEN` still works for scripts.
- Login routes lock out after repeated failures (429). Public routes are rate-limited per IP (429 + `Retry-After`).
- `GET /api/match` only serves matches already in our fixtures/results; others return 404.
- `/api/admin/team-stats/*` and `/api/admin/player-stats/*` are admin-only; agents can add/list/delete results.
- `POST /api/refresh` is limited to once per 5 minutes.
- Request bodies have length/range limits (422 when exceeded).
